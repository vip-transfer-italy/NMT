# НМТ Легко — підготовка до НМТ

Веб-застосунок для підготовки до НМТ: **українська мова, математика, історія України, географія**.
Працює в браузері на комп'ютері й телефоні, без реєстрації і сервера. Прогрес зберігається на пристрої (localStorage).
Застосунок можна встановити на телефон: «Додати на головний екран».

## Можливості
- Щоденний план на 1 / 1,5 / 2 години: теорія → практика → повторення, слабкі предмети стоять першими.
- Теорія простими словами, лише те, що перевіряють на НМТ.
- Завдання у форматі НМТ: один варіант із кількох, відповідність, хронологія, відкрита відповідь.
- Інтервальне повторення помилок (1, 3, 7, 14, 30 днів).
- Пробний НМТ з таймером, орієнтовний бал і розбір помилок.
- XP, рівні, серія днів, досягнення, прогноз балу для кожного предмета.

## Структура
```
nmt/
├── index.html
├── css/app.css
├── js/app.js            ← логіка (план, сесії, повторення, екрани)
└── js/data/*.js         ← теорія й завдання за предметами
```

## Як додати завдання
У файлі предмета (`js/data/ukr.js`, `math.js`, `history.js`, `geo.js`) додай об'єкт у `questions` потрібної теми:
```js
{ q: "Питання", o: ["правильний", "хибний", "хибний", "хибний"], a: 0, e: "Пояснення" }          // один варіант (варіанти перемішуються)
{ t: "open", q: "Питання", a: ["1.5"], e: "Пояснення" }                                       // відкрита відповідь (число)
{ t: "match", q: "...", l: ["1", "2"], r: ["А", "Б", "В"], a: [0, 1], e: "..." }             // відповідність
{ t: "order", q: "...", items: ["найраніше", "...", "найпізніше"], e: "..." }                 // хронологія
```
Важливо: нові питання додавай у **кінець** списку теми, бо від порядку залежить прогрес користувачів.
